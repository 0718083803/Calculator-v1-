# Calculator App

A simple web-based calculator built with HTML, CSS, and JavaScript.

## Description

This project is a basic calculator that allows users to perform arithmetic operations such as:
- Addition
- Subtraction
- Multiplication
- Division
- Clear display
- Evaluate expressions

It is designed as a beginner-friendly JavaScript project and can be used as a base for learning frontend development.

## Features

- Basic arithmetic operations
- Number input buttons
- Decimal support
- Clear function
- Evaluate button
- Simple and responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript
